# Excel 批量导入资源说明

## 概述

管理员可通过上传 Excel 文件（`.xlsx`）批量导入学习资源。后端使用 `openpyxl` 解析 Excel，将每一行转换为 `Resource` 数据库记录。

## Excel 模板格式

### 列定义（共 7 列，顺序固定）

| 列 | 字段名 | 是否必填 | 说明 |
|---|---|---|---|
| A | 标题 | **必填** | 资源名称 |
| B | URL | **必填** | 资源链接地址 |
| C | 描述 | 选填 | 简短描述 |
| D | 详细介绍 | 选填 | 详细说明文字 |
| E | 标签(逗号分隔) | 选填 | 多个标签用英文逗号分隔，如 `课程,笔记,考研` |
| F | 平台 | 选填 | 资源所在平台，如 `GitHub`、`B站`、`知乎` |
| G | 所属学科ID | **必填** | 必须为系统中已存在的学科 ID |

### 示例数据

| 标题 | URL | 描述 | 详细介绍 | 标签(逗号分隔) | 平台 | 所属学科ID |
|---|---|---|---|---|---|---|
| 示例：数据结构课程笔记 | https://example.com/ds-notes | 一份详尽的数据结构学习笔记 | 本资源涵盖了线性表、栈、队列、树、图等核心数据结构... | 课程,笔记,考研 | GitHub | c |

### 约束规则

1. **文件格式**：仅支持 `.xlsx`，不支持 `.xls`
2. **标题行**：第一行为表头，导入时自动跳过
3. **空行**：数据行全空则自动跳过
4. **列数**：每行至少需要 7 列，不足则报错
5. **标题和 URL**：任一为空，该行跳过并记录错误
6. **所属学科ID**：为空或系统中不存在，该行跳过并记录错误（提示请先在管理面板「学科管理」中添加）
7. **重复检测**：同一 URL + 学科ID 与已有资源重复时自动跳过；同一文件内重复行也自动跳过
8. **错误处理**：不符合规则的行被跳过，不影响其他行的导入

## Excel → JSON 转换逻辑

代码位置：`backend/app/routers/admin.py` 第 62-150 行

### 整体流程

```
Excel 文件 → openpyxl 解析 → 逐行校验 → 字段映射 → Resource ORM 对象 → SQLite 入库 → 返回 JSON
```

### 字段映射规则

| Excel 列 | Resource 字段 | 转换逻辑 |
|---|---|---|
| 标题 | `title` | 直接取字符串，去除首尾空格 |
| URL | `url` | 直接取字符串，去除首尾空格 |
| 描述 | `description` | 直接取字符串，去除首尾空格；空值存 `None` |
| 详细介绍 | `detailed_description` | 直接取字符串，去除首尾空格；空值存 `None` |
| 标签(逗号分隔) | `tags` | 按逗号拆分 → 去除每项首尾空格 → 过滤空项 → `json.dumps()` 转为 JSON 数组字符串 |
| 平台 | `platform` | 直接取字符串，去除首尾空格；空值存 `None` |
| 所属学科ID | `subject_id` | 直接取字符串，去除首尾空格 |

### 标签转换示例

```
Excel 单元格: "课程,笔记,考研"
              ↓ split(",") + strip
Python 列表:  ["课程", "笔记", "考研"]
              ↓ json.dumps(ensure_ascii=False)
JSON 字符串:  ["课程", "笔记", "考研"]
```

### 自动填充字段

每行资源导入时，以下字段由系统自动填充（**不在 Excel 列中**，无需手动填写）：

| 字段 | 值 | 说明 |
|---|---|---|
| `id` | `res_` + 12位随机 hex | 资源记录的主键，如 `res_a1b2c3d4e5f6` |
| `created_at` | 导入时刻毫秒时间戳 | 同一批导入的所有资源共享同一时间戳 |
| `status` | `"approved"` | 导入即通过审批 |
| `visibility` | `"public"` | 公开可见 |
| `submitter_id` | 当前管理员 ID | 导入操作人 |
| `client_id` | `"default"` | 共享数据，所有用户可见 |

> **区分**：此处的 `id` 是资源记录自身的唯一标识，与 Excel 中手动填写的「所属学科ID」（映射到 `subject_id` 字段）是不同的概念。学科的 ID 格式由添加方式决定：手动添加时为自定义 ID（如 `c`、`math`），快速添加时自动生成 `sub_1`、`sub_2` 等。

### 接口响应格式

```json
{
  "created": 5,
  "errors": [
    {"row": 3, "error": "标题和URL为必填项"},
    {"row": 7, "error": "学科ID 'bad_id' 不存在"}
  ]
}
```

- `created`：成功导入的资源数量
- `errors`：跳过的行及原因，便于修正后重新上传

## 学科管理

管理员可在「学科管理」标签中维护系统的学科列表，学科是资源分类的基础单位。

### 添加学科（两种方式）

| 方式 | 入口 | 接口 | 说明 |
|---|---|---|---|
| **快速添加** | 侧边栏底部输入框 + 按钮 | `POST /admin/subjects/auto` | 只需填写学科名称，系统自动生成 ID（格式 `sub_1`、`sub_2`…），适合快速建科。前端实际发送 `{id: '', name: '...'}`，后端忽略传入的 id 并自动分配 |
| **手动添加** | 管理面板 → 学科管理 → 输入学科ID + 名称 → 添加 | `POST /admin/subjects` | 需同时填写学科ID（小写字母开头，可含数字、下划线）和名称，适合需要自定义 ID 的场景 |

### 编辑与删除

- 点击学科行右侧的「编辑」按钮，可**修改学科ID和名称**，修改 ID 时会**自动级联更新**所有关联资源和稍后再学记录
- 点击「删除」可移除学科（仅当该学科下无公开资源时允许删除）

### 注意事项

- 导入 Excel 前，请确认表格中引用的学科ID 已预先创建，否则对应行会跳过并报错

### 相关接口

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/admin/subjects` | 获取所有学科列表 |
| `POST` | `/admin/subjects` | 手动添加学科（需同时提供 ID 和名称） |
| `POST` | `/admin/subjects/auto` | 快速添加学科（自动生成 ID，仅需名称） |
| `PATCH` | `/admin/subjects/{id}` | 修改学科 ID 或名称（级联更新关联数据） |
| `DELETE` | `/admin/subjects/{id}` | 删除学科（无公开资源时允许） |
